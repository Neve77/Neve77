# GitHub Profile README

## Instalação

1. Crie um repositório público com o nome exato do seu usuário do GitHub.
2. Coloque o `README.md` deste pacote na raiz do repositório.
3. Faça commit e push.
4. O GitHub exibirá automaticamente o README no seu perfil.

## Antes de publicar

Edite no `README.md`:
- `Neve77` caso seu username seja diferente.
- O link do LinkedIn.
- O endereço de e-mail.
- Descrições dos projetos, se quiser.

## Contribution Snake

O README inclui uma referência para:

`https://raw.githubusercontent.com/Neve77/Neve77/output/github-contribution-grid-snake.svg`

Para gerar esse arquivo automaticamente, será necessário configurar uma GitHub Action de contribution snake no repositório do perfil.
